# RKO Demo

Публичная демонстрационная версия интерфейса образовательной платформы RKO.

В демоверсии используются только вымышленные материалы. Здесь нет настоящих аккаунтов, паролей, закрытого курса, базы данных, пользовательских файлов и рабочей панели администратора.

Для входа подходят любые непустые логин и пароль.
