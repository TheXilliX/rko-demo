# RKO Demo

Публичная демонстрационная версия проекта RKO для публикации в Telegram.

Сейчас репозиторий служит безопасной заглушкой. Здесь не будет:

- настоящих аккаунтов и паролей;
- закрытых материалов курса;
- рабочей панели администратора;
- базы данных;
- приватных файлов и контактов учеников.

Демонстрационный сайт будет добавлен после утверждения основного интерфейса.
